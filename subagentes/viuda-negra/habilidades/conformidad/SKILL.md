# Revisión de conformidad

Fijá SHA y base revisados; enumerá flujos y criterios afectados. Contrastá comportamiento y cambios reales con especificación, plan y reglas aplicables del destino.

Para cada diferencia, indicá severidad, condición, archivo o artefacto y evidencia; distinguí defecto confirmado de hipótesis y cobertura pendiente. Entregá conformidad o hallazgos a Jarvis y referencias para Pantera. Si cambia el candidato, identificá verificaciones invalidadas. No conviertas compilación o un test verde en cobertura de dimensiones no comprobadas.
